# Changelog

## 1.0.0 - 2026-11-13

- Admin grid and form for CSP fetch hosts, with storefront, admin and global scope.
- Collector appends the active hosts to the Content-Security-Policy header Magento already builds.
- Host list cached for 24 hours and dropped, together with the full page cache, when a host changes.
- Brazilian Portuguese translation for the admin.
